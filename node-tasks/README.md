# node-tasks

Espacio reservado para **tareas livianas/serverless** con Node.js (P1).

## Alcance

- Node.js solo se usa cuando realmente aporta valor: actualizaciones o procesos puntuales, notificaciones y tareas auxiliares.
- **No** se traslada lógica arbitraria desde FastAPI a Node.js (P1, regla `backend.md`).
- Cada función Node.js debe **justificarse** antes de crearse (qué aporta y por qué no va en FastAPI).
